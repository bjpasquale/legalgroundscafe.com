# legalgroundscafe.com

Static site for Legal Grounds Café, Elsmere, Delaware. Built with `node build.mjs`, hosted on
GitHub Pages. See `CLAUDE.md` for how the pieces fit.

## Editing content
- Menu: `data/menu.json` — items, prices, `tags` (`V`, `VG`, `GF`), and a `seasonal` block that
  shows at the top of the menu when it has items.
- Hours and closures: `data/hours.json` — `closures` show a banner site-wide the day before and
  the day of; `overrides` change hours for one date.
- Press and quotes: `data/press.json`.
- Address, phone, links: `data/site.json`.
